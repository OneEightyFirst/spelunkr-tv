Spelunkr TV

An unofficial app that plays spelunkr.tv full screen on Fire TV and Android TV, controlled with your remote.

Download APK ({{VERSION}})

Install on a Fire TV

  1. On the Fire TV, install Downloader (by AFTVnews) from the Amazon Appstore.
  2. Settings → My Fire TV → Developer Options → Install unknown apps → turn on Downloader. (No Developer Options? Settings → My Fire TV → About, then press OK on the device name 7 times.)
  3. Open Downloader and enter:
    oneeightyfirst.github.io/spelunkr-tv/spelunkr-tv.apk
  4. Choose Install. Spelunkr TV appears in your apps.

On other Android TVs, use any file-downloader app with the same address and allow it to install unknown apps.

Remote

  • Arrows / OK: move and select, exactly like the website.
  • Back: closes menus and goes back a screen. On the first screen, press it twice to exit.
  • Play/Pause, Rewind, Fast-forward: passed to the site.

What this app does (and doesn't)

  • It is a single full-screen web view of https://spelunkr.tv/. Nothing else.
  • Its only permission is Internet. No storage, location, microphone, contacts or anything else.
  • It refuses to open any site other than spelunkr.tv.
  • No ads, analytics, trackers or third-party libraries. No connection from the page into the app.
  • The whole thing is one ~250-line Java file. Read the source.
